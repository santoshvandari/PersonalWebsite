# Santosh Bhandari — Portfolio

Personal portfolio of Santosh Bhandari, Python backend developer. Editorial, typography-driven design built with Next.js, TypeScript, and Tailwind CSS.

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Stack

- Next.js (App Router) + TypeScript
- Tailwind CSS v4
- next/font (Archivo, IBM Plex Sans, IBM Plex Mono)

## Structure

- `app/` — routes, layout, metadata, sitemap/robots
- `components/` — layout, navigation, sections, typography, UI
- `lib/` — site config and content (edit here to update copy)

## Build

```bash
npm run build
npm run start
```
